# Computational Mathematics 2026-2027

**🇹🇼 Ivy Collegiate Academy — Taichung, Taiwan**

> **Canonical source of truth.** The markdown masters for this course live in this private repo. Version-controlled via git. Production surfaces — syllabus doc, unit lesson plans, project rubrics, worksheets — are generated FROM these files and live in the school Drive under a corresponding folder structure.

A full-year computational mathematics course (prerequisite: Pre-Calculus) based on *Doing Math with Python* by Amit Saha, with a security/privacy lens throughout. Project-based, one multi-week project per unit. M-W-F coding / T-Th reflection rhythm.

## Unit Overview

| # | Unit | Book Chapter | Core Math | Security Lens | Project |
|---|------|-------------|-----------|---------------|---------|
| 0 | **Course Survey** | — | What / Why / How of comp math. Python exposure check, algorithmic thinking, math comfort self-assessment | Why math powers security | *Paper survey + discussion* |
| 1 | **Working with Numbers** | Ch 1 | Variables, types, operators, control flow, iterative computation, unit conversions | Integer overflow, safe arithmetic, input validation | *Calculator with Guardrails* |
| 2 | **Visualizing Data** | Ch 2 | Matplotlib, line/bar/scatter plots, axes, labels, reading data from files | Misleading charts, data integrity | *Visualizing Threats* |
| 3 | **Describing Data with Statistics** | Ch 3 | Mean/median/mode, variance/stdev, distributions, CSV data analysis | PII, anonymization, aggregation privacy | *Privacy-Aware Stats Dashboard* |
| 4 | **Algebra and SymPy** | Ch 4 | Symbolic math, equation solving, substitution, factoring, modular arithmetic | Modular arithmetic for ciphers, hashing for integrity | *Cipher Toolkit* |
| 5 | **Sets and Probability** | Ch 5 | Sets, unions/intersections, probability, random variables, expected value | Threat modeling, risk matrices, attack probability | *Risk Simulator* |
| 6 | **Geometry and Fractals** | Ch 6 | Coordinate systems, transformations, recursion, fractals | Pattern detection, geometric hashing | *Fractal Detection Models* |
| 7 | **Calculus and Modeling** | Ch 7 | Limits, derivatives, integrals (conceptual+programmatic), projectile motion | Anomaly detection, rate-of-change analysis | *Anomaly Trend Analyzer* |
