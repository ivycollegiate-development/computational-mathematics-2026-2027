# Unit 1 Assessments

## The paper

[`Unit-1-Assessment.md`](Unit-1-Assessment.md) — 50 points, 35 minutes,
closed computer, pen and paper only.

**Print double-sided before class.**

| Section | Points | Covers |
|---|---|---|
| A — Short Response | 20 | 10 questions: `/` vs `//`, `input()` conversion, `ValueError`, quiet vs crash, truth table, `Fraction` vs `float`, modulo, precision order, `get_number()`, security lens |
| B — Code Reading | 10 | Problem 11 (the price loop), Problem 12 (the broken `f_to_c`) |
| C — Boundaries | 10 | −273.15 °C / 0 K guard, the `10**15` ceiling and why it exists |
| D — Write Code | 10 | `get_int(prompt)` — validate, re-ask, refuse out of range |

Do not deviate from the printed paper. The coversheet carries the student's name,
their confident item, and the "one thing I hope is NOT on the test" note that
tells us where to spend Unit 2 review time.

## The key

[`Unit-1-Assessment-Answer-Key.md`](Unit-1-Assessment-Answer-Key.md) — **teacher
copy, do not distribute to students.** Per-item point splits, model answers,
the Section D rubric (`eval()` is an automatic zero for the question), and
grading bands that route each score range to U1-L17 or to a conversation.

## Where this sits in the sequence

Lesson files carry no dates, so this is the ordering reference for the end of
Unit 1:

| Lesson | Role |
|---|---|
| `U1-L14-Unit-1-Review-and-Catch-Up.md` | Diagnose — traffic-light every topic, your Reds become the study list |
| `U1-L15-Unit-1-Review-Session-2-and-Exam-Strategy.md` | Consolidate — work the Reds, learn to read the verb, 20-minute paper stress test |
| `U1-L16-Unit-1-Crash-Course-Before-the-Assessment.md` | Repair — reproduce each Red, then fix it in the calculator |
| **This assessment** | **The paper** — administered on the U2-L01 lesson day |
| `U1-L17-Reteach-Fixing-What-the-Assessment-Exposed.md` | Reteach — graded paper back, find the gap, reproduce the miss |
| `U2-L01-Unit-1-Assessment-and-Reflection.md` | Administer the paper + walkthrough + journal |

The assessment is administered during the U2-L01 lesson period, which is why
that lesson lives in the Unit 2 folder. It assesses Unit 1 content, not Unit 2.

## A note on keys

This repo is **public**. Every `*-Answer-Key*.md` file is gitignored on purpose
— a student can clone this and read the key. Keys live in the school Google
Drive, not here. If you add a key to this folder it will not be committed, which
is correct; copy it to Drive instead.
