## Part 2 — Five questions for any chart (15 min)

Apply all five to the chart on the board.


| # | Question | My answer |
|------------|------------|------------|
| 1 | **What is plotted?** What is on each axis — quantity, unit, time span?          |                                                                      |
| 2 | **What is omitted?** Where do the axes start? Any years, groups, or cases missing? |                                                                      |
| 3 | **Who made it?** What do they *want* you to conclude?                           |                                                                      |
| 4 | **Who is the audience?** What do they already believe?                          |                                                                      |
| 5 | **Story vs truth?** Does the visual emphasis match what the numbers support?   |                                                                      |

## Part 3 — Case study: the truncated axis (15 min)

```text
Data:   Jan 100,  Feb 101,  Mar 103,  Apr 102,  May 104

Chart A: y-axis from 0 to 110     → gentle, honest slope
Chart B: y-axis from 99 to 105    → dramatic, terrifying mountain
```

Both charts are technically true. Fill in the numbers yourself first.


| Question | My answer |
|------------|------------|
| Total change from Jan to May                                         |                                        |
| Total change as a percent of the FULL range (110 − 0 = 110)          |                                        |
| Total change as a percent of the TRUNCATED range (105 − 99 = 6)      |                                        |
| Roughly how many times LARGER does Chart B make the change look?     |                                        |
